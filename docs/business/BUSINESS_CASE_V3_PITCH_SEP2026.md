## 0. Verdict — le business est-il encore réaliste ?

**Oui — la thèse est réaliste.** Les montants absolus du V2 (5,5 / 11 / 23 k$/mois) restent un **plancher d’illustration réseau**, pas une preuve que « on y est ».

| Dimension | Verdict | Pourquoi |
|-----------|---------|----------|
| **Modèle** (cadeau 0 $ → Soft Cap chez la famille → RevShare 30 % Net) | ✅ Solide | Contourne le frein CA + le malaise vendeur au comptoir |
| **Grille Quiet Luxury** (Héritage / Éternité / Légendaire) | ✅ Alignée | Identique au canon FREEMIUM ; V2 n’est pas drifté sur les prix |
| **Unit economics** (~22 $ → ~43 $/famille entrante) | ✅ Crédibles | Waterfall réel ; viral = levier, pas condition de survie |
| **Volume 3 000 fam./an** | ⚠️ Mal cadré si dit « 1 salon » | Bannière historique ; volume réel Bourgie **plus haut** — laisser Patrice multiplier |
| **Scénario Base / Optimiste viral** | ⚠️ Aspirational | Produit Sanctuaire/Fonds **livré** ; flag tenant souvent OFF ; **zéro cohorte Stripe** publique dans ce repo |
| **Export master / Creatomate cinéma** | 🟡 Risque pitch | P0 gate livré ; master Stingray / rendu cinéma encore ⏳ — ne pas promettre le jour J funérailles |
| **Activation conseillers** | 🟡 Vrai kill | Business case meurt si non-usage silencieux — pas si « le VP n’aime pas le ciel » |

**En une phrase pour demain :**  
*Le modèle unitaire tient sans viral ; le viral double presque la commission ; l’échelle dépend de l’activation succursale et d’un export digne — pas d’une slide Optimiste.*

## 2. Unit economics (ancrage pitch — ne pas négocier la grille ici)

Référence waterfall : Platform Fee **10 %** → RevShare partenaire **30 % du Net** (B2B2C). Détail : [`../PARTNER_REVSHARE.md`](../PARTNER_REVSHARE.md).

| SKU famille (extrait) | Prix | Commission partenaire (ordre) |
|-----------------------|------|-------------------------------|
| Souvenir | 0 $ | 0 |
| Héritage | **179 $** | **~48 $** |
| Éternité | **349 $** | **~94 $** |
| Légendaire | **499 $** | N/A B2C (pas de RevShare salon) |

**Lecture orale (Script de Fer) :**

- Famille seule, Soft Cap conservateur → **~22 $** de commission **par famille entrante** (funnel, pas « par payante »).
- Avec Fonds / viral actif → **~43 $** — le levier **double presque** l’économie unitaire.
- Sur hyp. historique **~3 000 fam./an bannière** : **~5,5 k$ → ~11 k$/mois** au niveau réseau — **plancher** ; volume 2026 réel = multiplier.

AOV famille payante (formule inchangée) :

```text
AOV ≈ mix_H×179 + mix_E×349 + mix_L×499 + attach_addons
```

On ne reprend **pas** les checkouts mensuels H1 du V2 comme « plan Odyssey sept. ». On parle **maturité**.

### H1 — Pilote (J+1 → J+45)

| Levier | Cible apprentissage (pas engagement CA) |
|--------|------------------------------------------|
| Activation | ≥ 80 % des dossiers pilote = invitation envoyée |
| Soft Cap → Héritage+ | Mesurer le **vrai** % (remplace H5 V2) |

**Kill pilote :** friction conseiller, bug jour J, ou Soft Cap qui casse la confiance → on pause (Script de Fer règle 3).

### H2 — Échelle bannière (après pilote vert)

| Scénario | Conversion payante (Soft Cap) | Viral | Commission réseau (illustration) |
|----------|-------------------------------|-------|----------------------------------|
| Conservateur | ~35 % | OFF | **~$ /famille × volume réel** ≈ plancher type **5,5 k$/mois** sur 3 k fam./an |
| Base | ~50 % | Pilote ON subset | Vers **~11 k$/mois** sur même plancher volume |
| Optimiste | ~65 % + mix Éternité | Large | V2 ~23 k$/mois — **ne pas promettre** avant données |

> Si Patrice donne un volume annuel 2026, recalculer **en direct** : `commission_mois ≈ (vol_an / 12) × $par_famille`.

## 4. Moteurs de marge (ordre de priorité réaliste)

1. **Activation succursale** — sans invitation, Soft Cap = 0.  
2. **Conversion Soft Cap → Héritage** — levier le plus sûr sans viral.  
3. **Attach add-ons** (Licence 39 $, Voix, Livre…) — AOV sans changer le forfait.  
4. **Boucle virale / Fonds** — double presque le $/famille **quand** flag ON + cercle actif.  
5. **B2C direct** — marge sans RevShare ; CAC ≠ 0 ; [`../B2C_GO_TO_MARKET.md`](../B2C_GO_TO_MARKET.md) — **après** film qu’on ose envoyer.  
6. **Mix Éternité / Légendaire** — Quiet Luxury, pas discount war.

Détail exécution : [`REVENUE_GROWTH_STRATEGY_SEP2026.md`](REVENUE_GROWTH_STRATEGY_SEP2026.md).

## 6. Ce qu’on dit demain / ce qu’on ne dit pas

**Dire**

- Cadeau 0 $ · achat chez la famille · 30 % du net.  
- ~22 $ / ~43 $ par famille entrante.  
- 5,5–11 k$ = **illustration bannière** sur hyp. historique ; volume réel = ×.  
- Pilote P0, kill switch clair.

**Ne pas dire**

- « 23 k$/mois garantis ».  
- « Par salon » pour les 3 000.  
- « Le master 4K cinéma est livré partout » si la démo n’est pas ce niveau.  
- « Le viral est ON partout » si le tenant démo est OFF.
