## 1. Thèse investisseur (30 secondes)

> *La mémoire et le deuil sont un marché mondial énorme, encore coincé dans l’USB et le courriel. Odyssey est le cheval de Troie B2B2C dans les réseaux funéraires (CAC famille ≈ 0). Phase 1 capture l’attention et le cash transactionnel. Phase 2 fidélise (MRR / Lyra / data consent). Phase 3 monétise le monopole d’attention : Marketplace — mise en relation avec une industrie annexée fragmentée (take-rate), sans produire les services.*

**Une phrase Sanji :**

> *Le Studio n’est pas le détail — c’est le wedge à CAC quasi nul. Lyra, c’est la rétention et le chef d’orchestre IA (admin / légal guidé pour le directeur et la famille). La Marketplace, c’est le Platform Play. On lève pour industrialiser le wedge et verrouiller les briques 2 puis 3.*

**Stack 1 → 2 → 3 (raisonnement CEO)**

| Phase | Rôle | Ce que ça prouve |
|-------|------|------------------|
| **1 Studio B2B2C** | **Acquisition** gratuite via salons | Distribution |
| **2 Lyra / MRR / graphe** | **Rétention** + **orchestrateur IA** (admin post-décès) + data | Stickiness · multiple · ops |
| **3 Marketplace** | **Extraction** valeur plateforme (CPL + take-rate tiers) | Platform margins |

## 4. Phase 1 — Le wedge (ce qui finance la boîte)

### Modèle

```text
Salon offre Souvenir 0 $ (geste 30 s)
  → Famille + cercle (Sanctuaire / Fonds)
  → Soft Cap → Héritage / Éternité / add-ons
  → Platform fee 10 % · RevShare partenaire 30 % Net
  → Odyssey garde le reste − COGS
```

**Unit economics (ordres de grandeur pitch) :**

| | $/famille entrante (commission partenaire) | Lecture Odyssey |
|--|---------------------------------------------|-----------------|
| Soft Cap seul (conservateur) | **~22 $** | Viral OFF — modèle déjà viable |
| + Fonds / viral | **~43 $** | Presque ×2 — levier, pas condition de survie |

Détail : [`BUSINESS_CASE_V3_PITCH_SEP2026.md`](BUSINESS_CASE_V3_PITCH_SEP2026.md) · [`VIRAL_EXPLAINED_SIMPLY.md`](VIRAL_EXPLAINED_SIMPLY.md).

### Pourquoi les investisseurs doivent aimer Phase 1

- **CAC famille ≈ 0** si le salon active (le risque = activation, pas ads).  
- **Paywall au pic émotionnel** (attachement), pas à l’entrée.  
- **Viral / Fonds = déjà produit** (flag tenant) — 2ᵉ moteur GMV sans attendre « Lyra ».  
- **Preuve de distribution** avant de scaler la data story.

### Risques Phase 1 (les nommer = crédibilité)

| Risque | Mitigation |
|--------|------------|
| Conseiller n’utilise pas | Règle 30 s · pilote 2 champions · scoreboard |
| Bug / export jour J | P0 gate · ne pas overpromettre master cinéma |
| Marge Fonds (crédits) | Seuil marge/projet · pilote flag ON limité |

## 5. Phase 2 — L’upside (Licorne roadmap)

**Source canon :** [`../VISION_PHASE_2.md`](../VISION_PHASE_2.md) — **pas** le même fichier que le cinéma [`../ROADMAP_PHASE2.md`](../ROADMAP_PHASE2.md).

| Pilier Phase 2 | Idée investisseur | État |
|----------------|-------------------|------|
| **Sanctuaire MRR** | Abonnement post-an 1 · actif familial vivant | Vision — pas V1 live |
| **Lead-Gen CPL** | Emails invités → pré-arrangements (funéraire) | Vision + consentement marketing |
| **LYRA Orchestrateur** | IA chef d’orchestre : checklists légales / admin, résiliations (tél., internet…), assist **directeur + famille** — humain scelle | Vision sept. 2026 · liability-critical |
| **Data Graph LYRA** | Faces / graphe / généalogie (consentement explicite) | Vision Manifesto · privacy-critical |
| **Moteur cinéma avancé** | Qualité A24 / scale rendu | Roadmap séparée · P0 fondations ✅ |

**Comment le dire :**

> *Phase 2, ce n’est pas “de la magie IA”. MRR mémoire, leads pré-arrangements, et Lyra comme chef d’orchestre — elle guide directeur et famille dans le labyrinthe admin (formulaires, résiliations), sans remplacer le notaire. Le graphe data, c’est l’actif long terme. Le Studio Phase 1 remplit le tuyau.*

**Comment ne pas le dire :**

> ~~Lyra remplit déjà tous les formulaires légaux et résilie les comptes toute seule, sans humain.~~
> ~~Lyra automatise déjà des milliers d’heures sans humain et nous rend infiniment scalables mondialement.~~

**Pont vers Phase 3 :** quand Lyra détecte « il faut une urne / une salle », elle **route** vers la Marketplace (partenaire first). Le CPL Phase 2 reste la marketplace thin B2B vers le salon.

## 6. Phase 3 — Agrégateur global (The « Everything » Marketplace)

> **Canon :** [`../VISION_PHASE_2.md`](../VISION_PHASE_2.md) §3ter. **Pas** dans le texte figé Manifesto juin 2026 — la vision stratégique vit dans VISION.

### Thèse (Platform Play)

Phase 1 capte à coût quasi nul. Phase 2 fidélise l’héritage.  
Phase 3 = **plus grande place de marché transactionnelle** de la mémoire : Odyssey **route** une demande captive vers une offre **mondiale hyper-fragmentée** (longue traîne). **Zéro inventaire.** Take-rate + rabais exclusif famille.

| Couche | Exemples | Message investisseur |
|--------|----------|----------------------|
| Circulaire B2B | Leads salles / concessions → **partenaires** | Ally des réseaux, pas Uber qui les tue |
| Manufacturier mondial | Urnes / cercueils flux tendu | Volume |
| Artisanat local | Ébéniste 3 pièces/mois | Longue traîne · discovery |
| Ultra-luxe / extrême | Diamants cendres · bio-urnes · niches orbitales | Aspiration · PR |

**Métaphore Sanji (doser) :** *On commence par les livres (film / souvenirs) ; on finit par router tout le reste de l’économie mémoire — sans stock.*

### Phrase deck

> *Le marché de la fin de vie est massif mais brisé. Nous sommes le premier point de contact numérique. Nous monétisons chaque intention d’achat — affiliation / take-rate — tout en redistribuant du business aux salons (salles, terrains). Marges plateforme pures.*

### Risques Phase 3

| Risque | Mitigation |
|--------|------------|
| « Amazon du deuil » = froid / indigne | Curated Quiet Luxury · opt-in · pas spam jour J |
| Salon se sent contourné | **Partenaire first** dans l’algo · revshare |
| Distraction vs wedge | Build **après** Phase 1–2 amorcées |
| Qualité / fraude vendeurs | Vetting · SLA · notation |

**Ask T0 :** industrialiser Phase 1 + briques Phase 2 — **pas** « on build la marketplace Q1 ».

## 9. Phrases convaincantes (Sanji / VC)

**Positionnement**

> *Nous n’achetons pas des familles. Nous empruntons le réseau qui les a déjà.*

**Wedge vs upside**

> *Le Studio est la porte d’entrée à CAC quasi nul. Phase 2, c’est la rétention (MRR / data). Phase 3, c’est le Platform Play — take-rate sur l’écosystème annexé. Sans Phase 1 qui convertit, il n’y a ni graphe ni marketplace à bâtir.*

**Marketplace**

> *Amazon a commencé par les livres. Nous commençons par le film et le coffre. Phase 3, on route toute l’économie fragmentée de la mémoire — take-rate, zéro stock — et on renvoie du business aux salons. Allié des réseaux, pas concurrent.*

**Viral / Fonds**

> *Le cercle paie aussi. On monétise la générosité, pas seulement la carte d’une personne en deuil — et le partenaire est aligné sur chaque dollar.*

**Privacy (quand ils attaquent)**

> *Phase 2 data graph = consentement explicite, séparé de l’upload transactionnel. Loi 25 n’est pas un détail — c’est dans la constitution produit.*

**Ask (template)**

> *On lève pour [X] : accélérer l’activation réseau, fiabiliser l’export digne, allumer le pilote Fonds, et poser les briques MRR / consent / CPL. La Marketplace est l’Endgame — pas la ligne budgétaire T0. Kill criteria clairs à 90 jours.*
