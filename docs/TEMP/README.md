## Règles

| OK dans `TEMP/` | Pas dans `TEMP/` |
|-----------------|------------------|
| Rush démo / checklist jour J | Prix / Soft Cap / RevShare (→ FREEMIUM, PARTNER_REVSHARE) |
| Brouillons de courriel | Inventaire frames durable (→ `DA_SCREENS.md`) |
| Notes session Figma / call | Copy écran (→ dictionaries + `COPY_CATALOG.md`) |
| Plan B si prod down | Playbook VP durable (→ `MEETING_PATRICE_VP.md`) |
| Exports one-shot pour un partenaire | Craft labs, SQL, Manifesto |

Quand un TEMP devient **stable** → le promouvoir (fusion dans un playbook/canon) **ou** le jeter / `_archive/`.  
Ne pas laisser pourrir 6 mois sans date dans le titre.
